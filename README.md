# Greenden Website 🌿

Greenden is a responsive plant shop website created using HTML and Tailwind CSS. The project features a modern and clean user interface with multiple pages including Home, Products, and Contact. It is designed to provide a smooth and user-friendly browsing experience across all devices.

## 🚀 Features
- Responsive Design
- Modern UI with Tailwind CSS
- Home Page
- Product Listing Page
- Contact Page
- Clean and Structured Code

## 🛠️ Technologies Used
- HTML5
- Tailwind CSS

## 📄 Pages
- Home
- Products
- Contact 

## 🎯 Project Purpose
This project was developed to improve frontend development skills and practice building responsive websites using Tailwind CSS.
